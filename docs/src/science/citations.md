# Citations

Agrocosm is scientifically informed by LPJmL. The core references for its crop,
soil, and nitrogen-process foundations, together with the NeuralCrop reference
for differentiable hybrid crop modelling, are maintained in
[`CITATIONS.md`](https://github.com/yunan-l/Agrocosm.jl/blob/main/CITATIONS.md).

The complete curated list of LPJmL publications is available from the
[LPJmL key-publications page](https://www.pik-potsdam.de/en/institute/departments/activities/biosphere-water-modelling/lpjml/key-publications).
